# wikipedia-trends

Agent Skill для аналізу переглядів Wikipedia. Локальний CLI на TypeScript/Node 20.
Без сервера, без БД, без UI.

## Жорсткі правила

- stdout кожної команди — компактний JSON, максимум 40 рядків.
  Великі дані (денні ряди, графіки, PDF) пиши у файли в `output/`,
  у stdout віддавай шлях + метадані.
- Жодних обчислень на боці моделі. Уся статистика, нормалізація
  й агрегація — у коді.
- Кожна нова функція в `src/lib/` — з тестом у `tests/`.
- TypeScript strict. Без `any`.
- HTTP у тестах мокати. Мережа з тестів заборонена.
- Не додавати скомпільовані бінарники. `dist/` не комітиться.

## Стек

Node 20, TypeScript, vitest. Залежності мінімальні —
перед додаванням пакета спитай.

## Структура

SKILL.md — роутер для агента (компактний, читається кожною сесією)
references/ — методологія, інтерпретація, нотатки про API (читаються за потреби)
scripts/setup.sh — ідемпотентне встановлення
src/cli.ts — точка входу, підкоманди
src/commands/ — research, resolve, fetch, analyze, compare, report
src/lib/ — уся змістовна логіка
tests/ — vitest
evals/ — прогін сценаріїв на швидкій моделі (витрачає токени)
assets/fonts/ — DejaVu Sans для кирилиці в PDF
output/ — згенеровані артефакти (в .gitignore)
.cache/ — кеш HTTP-відповідей (в .gitignore)
