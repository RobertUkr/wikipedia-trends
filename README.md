# wikipedia-trends

Agent Skill для аналізу динаміки інтересу до тем за даними переглядів Wikipedia.

Допомагає командам B2C-продуктів відповідати на питання на кшталт «чи зростає
інтерес до астрономії в україномовній аудиторії» та «якою мовою запускати продукт
наступною» — з явною оцінкою того, наскільки знайденому тренду можна довіряти.

## Що вміє

- Резолвить тему через Wikidata в точні заголовки статей у різних мовних розділах
- Тягне статистику переглядів Wikimedia Pageviews API з кешуванням
- Нормалізує дані між мовами, відділяє сезонність і новинні сплески від тренду
- Рахує скор достовірності висновку
- Генерує графіки та одностраничний PDF-звіт

## Стек

Node 20, TypeScript. Локальний CLI без сервера та бази даних.

## Установка

```bash
npm ci
npm run build
```

## Використання

```bash
node dist/cli.js resolve --topic "інтервальне голодування" --lang uk [--langs pl,cs]
node dist/cli.js fetch --qid Q1666254 --langs de,cs --from 2023-09-01 --to 2025-09-01 [--no-cache] [--out file.json]
```

`resolve` шукає тему у Wikidata й повертає Q-ID та заголовки статей у всіх мовних
розділах. Якщо кілька кандидатів мають близький скор — повертає їх у `candidates`
з `ambiguous: true` і не вибирає за вас.

`fetch` тягне денні перегляди (`access=all-access`, `agent=user`) для кожної мови
окремо й повідомляє про прогалини в даних.

Відсутність статті в мовному розділі — це висновок, а не збій: така мова йде
в поле `unavailable` з класифікацією, а решта мов тягнеться як звичайно.

- `no_article` — пошук у розділі не знайшов статті про тему
- `possible_alternative` — є стаття зі схожою назвою; вона НЕ підтверджений
  відповідник (`confirmed: false`), потрібне підтвердження користувача
- `no_data` — стаття є, але Pageviews API не має даних за період
- `fetch_failed` — технічний збій запиту, не висновок про мову

stdout обох команд — компактний JSON. Денні ряди та повний список заголовків
пишуться у `output/`, відповіді Pageviews API кешуються в `.cache/` на 24 години.

Змінні середовища:

- `WIKIMEDIA_CONTACT` — контакт у User-Agent, вимога політики Wikimedia
- `WIKIPEDIA_TRENDS_CACHE_DIR` — альтернативний каталог кешу

## Обмеження

Перегляди статей Wikipedia — проксі-сигнал інтересу, а не готовності платити.
Мовний розділ не дорівнює країні. Детальний опис припущень і обмежень
